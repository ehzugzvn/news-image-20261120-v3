# THE GLOBAL FRONT PAGE — news-image-20261120 (v3)

One image that sums up Friday 20 November 2026: a maximal broadsheet front page with three illustrated leads (the Kyiv barrage on the Dnipro bridges, Cyclone Akvan's landfall at Gopalpur, and COP31's deadlocked final day in Antalya), a dot-matrix world map with pins keyed to the story numbers, a UTC timeline rail, and all 43 stories as numbered cards under seven colour-banded region headers — with the date carried in the masthead strip, the standfirst, and a black DATE CHECK strip so the day can never be missed. `entry.png` is rendered by `render.py` (PIL, Liberation fonts in `fonts/`); `main.py` simply copies the committed page to the output directory.
